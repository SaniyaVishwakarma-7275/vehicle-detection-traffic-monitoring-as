# AI-Based Vehicle Detection and Traffic Monitoring System

## Overview

This project aims to develop an AI-based traffic monitoring system that detects and tracks vehicles in recorded traffic videos. The system is being developed as a final-year B.Tech project.

## Objectives

* Detect vehicles in traffic videos.
* Track vehicle movement across video frames.
* Support vehicle counting and traffic monitoring.
* Develop additional traffic violation detection features.

## Technology Stack

* Python
* Ultralytics YOLOv8
* OpenCV
* ByteTrack

*Include each technology above only if it is actually used in the current implementation.*

## Planned Features

* Vehicle Detection
* Number Plate Detection
* Number Plate Recognition (OCR)
* Helmet Detection
* Red-Light Violation Detection
* Wrong-Way Driving Detection
* Speed Estimation
* Illegal Parking Detection
* Vehicle Counting
* Automatic Evidence Capture
* Web Dashboard and Database Integration
